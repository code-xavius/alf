Nuage de mots

Posez une question, chacun envoie un mot, le nuage se construit en direct.

Vote en direct

Sondez la salle en quelques secondes et affichez les résultats à l'écran.

Quiz

Questions à choix multiple ou simples choix. Les élèves peuvent corriger leur réponse ; vous révélez la bonne réponse quand vous le décidez.

Simple à lancer

Un code et un QR code suffisent. Vos élèves répondent depuis leur téléphone, sans installation.

Intégrez alf à vos présentations

Affichez vos activités directement dans vos diapositives : via une iframe dans Reveal.js, ou via le complément Web Viewer dans PowerPoint.

Prêt en quelques minutes.

  1. Créez votre activité et préparez vos questions.
  2. Projetez le QR code ou partagez le lien.
  3. Suivez les réponses et les résultats en direct.
